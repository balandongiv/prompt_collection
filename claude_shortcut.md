In **Claude / Claude Code, it’s actually the same shortcut** 👍

* **`Ctrl + U`** → **clear current input line** (delete from cursor to start, usually clears whole line)
* **`Ctrl + K`** → delete from cursor to **end of line**
* **`Ctrl + Y`** → paste back what you deleted with `Ctrl+U` or `Ctrl+K` ([Claude][1])

So if you’re used to **Codex `Ctrl+U`**, Claude Code behaves the same.

### Useful Claude extras

A few nearby shortcuts people use a lot:

* **`Ctrl + L`** → clear terminal screen, keep session
* **`Esc Esc`** → rewind conversation to previous point
* **`Ctrl + C`** → stop generation / cancel current input
* **`Ctrl + D`** → exit Claude Code ([Tim Dietrich][2])
